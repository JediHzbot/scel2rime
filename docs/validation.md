## 回归覆盖

- 未知魔数、逐字节截断、非法 UTF-16/控制字符、异常词条及旧版元信息提示。
- 同批次同名冲突，即使 `--force` 也不互相覆盖。
- 缺失输入、部分恢复、输出写入失败和批处理继续执行。
- 原子替换失败时保留旧输出，临时文件清理。
- CLI 与安装器预演不产生输出或配置变更。
- 输入目录缺失或为空、保留词典名、文件名/头部名称不符，在修改前拒绝。
- 被覆盖词典进入备份；回滚恢复旧内容并删除本次新增受管文件。
- 备份遭修改时拒绝恢复；不把多个备份混用。
- 自定义用户目录传递给部署器，默认用户目录不受影响。
- 旧二进制不能充当新编译成功证据。
- 原生子进程失败、超时和 ERROR/FATAL 日志触发失败与恢复。

集成测试在临时脚本副本中替换 native worker，以模拟异常和成功；真实引擎验证是独立的额外检查，不以模拟测试冒充实际编译。
